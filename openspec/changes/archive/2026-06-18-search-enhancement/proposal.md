# Proposal: 搜索增强功能

## 业务需求
面向最终用户的搜索增强工具。解答人员在工作中积累了大量的已解答问题、文档（Wiki/PDF/Word/Text）和应用跳转链接，最终用户搜索时能获得相关结果和关联推荐。

## 核心能力
- **混合检索**：向量语义搜索（近义词理解）+ BM25 关键词搜索（拼写容错），RRF 融合排序
- **标签关联推荐**：基于标签关联，搜索结果同时推荐相关文档、FAQ 和应用跳转链接
- **多源数据加载**：支持 Wiki、PDF、Word、Text、在线链接多种来源

## 非目标
- 不做实时爬取，使用预构建索引或 Mock 数据
- 不做权限管理
- 不做前端界面，仅提供 Python API 示例
